📖 Manuel de référence

Formules, méthodes et exercices pour l'électronique

📐 Formules essentielles

⚡ Électricité de base

Loi d'Ohm
U = R × I
U = tension (Volts) · R = résistance (Ohms) · I = intensité (Ampères)
Puissance électrique
P = U × I = R × I² = U² / R
P = puissance (Watts) · U = tension (V) · I = intensité (A) · R = résistance (Ω)
Diviseur de tension (2 résistances)
Vs = Ve × R2 / (R1 + R2)
Vs = tension de sortie · Ve = tension d'entrée · R1 et R2 = résistances
Diviseur de courant (2 résistances)
I1 = I × R2 / (R1 + R2)
I1 = courant dans R1 · I = courant total · R1 et R2 = résistances
Résistances en série / parallèle
Série : Req = R1 + R2 + R3...
Parallèle : 1/Req = 1/R1 + 1/R2 + 1/R3...

📊 Filtres RC

Fréquence de coupure (filtre passe-bas / passe-haut)
fc = 1 / (2 × π × R × C)
fc = fréquence de coupure (Hz) · R = résistance (Ω) · C = capacité (F)
Constante de temps RC
τ = R × C
τ = constante de temps (s) · R = résistance (Ω) · C = capacité (F)
Temps de charge / décharge (à 63% et 99%)
t(63%) = τ · t(99%) = 5 × τ

〰️ Signaux alternatifs

Valeur efficace (RMS) — signal sinusoïdal
Vrms = Vmax / √2 ≈ 0,707 × Vmax
Vmax = amplitude crête · Vrms = valeur efficace
Valeur efficace — signal carré
Vrms = Vmax
Pour un carré symétrique (0V / Vmax), Vrms = Vmax × √D (D = rapport cyclique)
Valeur efficace — signal triangulaire
Vrms = Vmax / √3 ≈ 0,577 × Vmax
Fréquence et période
f = 1 / T
f = fréquence (Hz) · T = période (s)

🔋 Alimentation

Puissance dissipée par un régulateur
P = (Ve - Vs) × I
Ve = tension d'entrée · Vs = tension de sortie · I = courant de sortie
Tension de sortie d'un régulateur ajustable (LM317)
Vs = 1,25 × (1 + R2 / R1)

🎛️ Transistor

Gain en courant (hFE)
Ic = hFE × Ib
Ic = courant collecteur · Ib = courant base · hFE = gain (100-300 pour 2N2222)
Résistance de base
Rb = (Vcommande - 0,7) / Ib
Vcommande = tension de commande · 0,7 = Vbe du transistor

🔧 Méthodes de travail

🔍 Dépannage d'un circuit en 5 étapes

  1. 1. Observation visuelle Vérifier les composants (brûlés, gonflés, noircis), les soudures (froides, cassées), les connexions (fils dénudés, faux contacts).
  2. 2. Vérification de l'alimentation Mesurer la tension aux bornes de la pile ou de l'alimentation. Vérifier la polarité. Remplacer la pile si nécessaire.
  3. 3. Mesure des tensions Au multimètre (mode V DC), mesurer les tensions aux points clés : entrée, sortie du régulateur, base du transistor, etc. Comparer aux valeurs attendues.
  4. 4. Test des continuités En mode ohmmètre (circuit hors tension), vérifier les connexions : entre les composants, les soudures, les pistes du circuit.
  5. 5. Remplacement par élimination Si plusieurs composants sont suspects, remplacer un par un (en commençant par les plus simples : pile, LED, résistance) pour isoler la panne.

📐 Choix d'une résistance pour une LED

  1. Connaître la tension d'alimentation (ex : 9V)
  2. Connaître la tension de la LED (Vf = 2V pour une rouge)
  3. Connaître le courant souhaité (I = 20mA = 0.02A)
  4. Calculer : R = (Valim - Vf) / I = (9 - 2) / 0.02 = 350Ω
  5. Choisir la valeur normalisée la plus proche : 330Ω ou 470Ω

⚡ Choix d'un transistor pour un moteur

  1. Connaître le courant du moteur (ex : 500mA)
  2. Choisir un transistor avec Ic max > courant moteur (2N2222 : 800mA ✓)
  3. Calculer le courant de base : Ib = Ic / hFE = 500mA / 100 = 5mA
  4. Calculer la résistance de base : Rb = (Vcommande - 0.7) / Ib
  5. Exemple : commande 5V → Rb = (5 - 0.7) / 0.005 = 860Ω → choisir 820Ω ou 1kΩ

📝 Exercices corrigés

Cliquez sur "Voir la solution" pour afficher la correction détaillée.

1

Calcul d'une résistance pour LED

On veut allumer une LED rouge (Vf = 2V) avec une pile de 9V. Le courant doit être de 20mA.
Quelle résistance faut-il choisir ?
Formule : R = (Valim - Vf) / I

Calcul : R = (9 - 2) / 0.02 = 7 / 0.02 = 350 Ω

Valeur normalisée la plus proche : 330 Ω (courant légèrement supérieur : 21mA) ou 470 Ω (courant plus faible : 15mA).

Choix conseillé : 330 Ω (la LED éclaire un peu plus) ou 470 Ω (la LED dure plus longtemps).
2

Diviseur de tension

On a une tension d'entrée de 12V. On veut une tension de sortie de 5V avec un courant faible.
On choisit R1 = 10kΩ.
Quelle valeur de R2 faut-il ?
Formule : Vs = Ve × R2 / (R1 + R2)

Réarrangement : R2 = R1 × Vs / (Ve - Vs)

Calcul : R2 = 10000 × 5 / (12 - 5) = 50000 / 7 = 7142 Ω

Valeur normalisée : 6,8 kΩ ou 7,5 kΩ.

Vérification avec 6,8kΩ : Vs = 12 × 6800 / (10000 + 6800) = 4,86V (proche de 5V ✓).
3

Filtre RC passe-bas

On veut un filtre passe-bas avec une fréquence de coupure de 1 kHz.
On dispose d'un condensateur de 100 nF.
Quelle résistance faut-il ?
Formule : fc = 1 / (2 × π × R × C)

Réarrangement : R = 1 / (2 × π × fc × C)

Conversion : C = 100 nF = 100 × 10⁻⁹ F = 1 × 10⁻⁷ F

Calcul : R = 1 / (2 × 3.14159 × 1000 × 1×10⁻⁷)
R = 1 / (6.283 × 10⁻⁴) = 1592 Ω

Valeur normalisée : 1,5 kΩ ou 1,6 kΩ.

Vérification avec 1,6kΩ : fc = 1 / (2π × 1600 × 100nF) = 995 Hz ✓.
4

Transistor en commutation

On veut commander un moteur de 300mA avec un transistor 2N2222 (hFE = 100).
Le signal de commande est une sortie logique 5V.
Quelle résistance de base faut-il ?
Étape 1 — Courant de base nécessaire :
Ib = Ic / hFE = 300mA / 100 = 3 mA

Étape 2 — Résistance de base :
Rb = (Vcommande - Vbe) / Ib = (5 - 0.7) / 0.003
Rb = 4.3 / 0.003 = 1433 Ω

Valeur normalisée : 1,5 kΩ (courant de base : 2,9 mA, suffisant).

Marge de sécurité : on peut prendre 1 kΩ (courant base 4,3 mA) pour être sûr que le transistor sature.
5

Temporisation RC

On veut qu'une LED reste allumée environ 3 secondes après avoir relâché un bouton.
On utilise un condensateur de 100 µF.
Quelle résistance faut-il ?
Formule : t = R × C (constante de temps τ)

Pour une décharge complète (5τ) : t = 5 × R × C

Réarrangement : R = t / (5 × C)

Conversion : C = 100 µF = 100 × 10⁻⁶ F = 1 × 10⁻⁴ F

Calcul : R = 3 / (5 × 1×10⁻⁴) = 3 / (5×10⁻⁴) = 6000 Ω

Valeur normalisée : 6,8 kΩ ou 10 kΩ.

Vérification avec 6,8kΩ : t = 5 × 6800 × 100µF = 3,4 s ✓ (proche de 3s).
