1. 📱 Présentation de l'application

2. ✅ Prérequis

Avant d'installer l'application, vérifiez que vous disposez de :

Élément Minimum requis
Navigateur Chrome, Edge, Firefox ou Safari (version récente)
Système Windows 10/11, Android 7+, iOS 12+, macOS 10.13+
Connexion Internet Uniquement pour l'installation (pas après)
Espace disque ~10 Mo
⚠️ Attention : Sur PC, utilisez Chrome ou Edge pour l'installation automatique. Firefox PC ne propose pas toujours l'installation, mais l'appli reste utilisable en ligne.

3. 🌐 Méthode 1 : Utiliser en ligne (sans installation)

La méthode la plus simple : ouvrez simplement le lien dans votre navigateur.

📋 Étapes

  1. Ouvrez votre navigateur (Chrome, Edge, Firefox, Safari...)
  2. Dans la barre d'adresse, tapez :
    https://abdelziane979-eng.github.io/initiaelectro/
  3. Appuyez sur Entrée
  4. L'application InitiaElectro s'affiche !
  5. Pour le bac à sable, cliquez sur la carte "🧪 Bac à sable"
💡 Astuce : Ajoutez cette page à vos favoris pour y accéder rapidement la prochaine fois.
✅ Avantages : Aucune installation, fonctionne partout.
❌ Inconvénients : Nécessite une connexion Internet.

4. 💻 Méthode 2 : Installer sur PC Windows (Chrome ou Edge)

Installez l'application comme un vrai logiciel, accessible depuis votre bureau.

⚠️ Important : Utilisez Chrome ou Edge. L'installation automatique ne fonctionne pas toujours sur Firefox PC.

📋 Étapes

  1. Ouvrez Chrome ou Edge
  2. Allez sur :
    https://abdelziane979-eng.github.io/initiaelectro/
  3. Attendez 5 à 10 secondes
  4. Dans la barre d'adresse, cherchez une icône ⊕ (cercle avec un +) ou 📲 (écran) à droite
  5. Cliquez sur cette icône
  6. Une fenêtre s'ouvre : cliquez sur "Installer"
  7. L'application s'ajoute à votre menu Démarrer et à votre bureau
💡 Astuce : Si l'icône ⊕ n'apparaît pas, fermez puis rouvrez Chrome/Edge, puis rechargez la page.
✅ Résultat : Une icône "InitiaElectro" apparaît dans votre menu Démarrer et sur votre bureau.

🧪 Installer aussi ElectroPremium

Répétez les mêmes étapes avec l'URL :

https://abdelziane979-eng.github.io/initiaelectro/bac_a_sable.html

5. 📱 Méthode 3 : Installer sur tablette Android

Sur Android, l'application s'installe facilement depuis Chrome.

📋 Étapes

  1. Ouvrez Chrome sur votre tablette Android
  2. Allez sur :
    https://abdelziane979-eng.github.io/initiaelectro/
  3. Appuyez sur le menu ⋮ (3 points en haut à droite)
  4. Choisissez "Installer l'application" ou "Ajouter à l'écran d'accueil"
  5. Confirmez en appuyant sur "Installer"
  6. L'icône apparaît sur votre écran d'accueil !
💡 Astuce : Sur tablette, l'appli s'ouvre en plein écran comme une vraie application.

6. 🍎 Méthode 4 : Installer sur iPad / iPhone

Sur iPhone/iPad, utilisez Safari pour installer l'application.

⚠️ Important : Utilisez Safari (pas Chrome), sinon l'installation ne fonctionnera pas.

📋 Étapes

  1. Ouvrez Safari sur votre iPhone/iPad
  2. Allez sur :
    https://abdelziane979-eng.github.io/initiaelectro/
  3. Appuyez sur l'icône Partager (carré avec flèche vers le haut)
  4. Faites défiler et choisissez "Sur l'écran d'accueil"
  5. Donnez un nom (ex: "InitiaElectro")
  6. Appuyez sur "Ajouter"
  7. L'icône apparaît sur votre écran d'accueil !

7. ✅ Vérifier l'installation

Comment savoir que l'application est bien installée :

Élément Signe que c'est bon
Icône Vous voyez un cercle bleu/violet avec une LED rouge
Nom "InitiaElectro" ou "ElectroPremium"
Ouverture L'appli s'ouvre en plein écran (sans barre d'adresse)
Hors ligne Déconnectez Internet : l'appli fonctionne toujours
🎉 Test final : Coupez votre WiFi, ouvrez l'appli. Si tout fonctionne, c'est gagné !

8. 🗑️ Désinstallation

Pour retirer l'application :

🖥️ Sur PC Windows

  1. Menu Démarrer → cherchez "InitiaElectro"
  2. Clic droit → "Désinstaller"
  3. Confirmez

📱 Sur Android

  1. Appui long sur l'icône
  2. Faites glisser vers "Désinstaller" ou choisissez "Supprimer"

🍎 Sur iPhone / iPad

  1. Appui long sur l'icône
  2. Choisissez "Supprimer l'app"

9. 🔧 Dépannage

❌ L'icône ⊕ n'apparaît pas dans la barre d'adresse

  • Vérifiez que vous utilisez Chrome ou Edge (pas Firefox PC)
  • Rechargez la page avec Ctrl + F5
  • Fermez et rouvrez le navigateur
  • Attendez 10 à 15 secondes après le chargement

❌ L'installation échoue

  • Vérifiez votre connexion Internet
  • Essayez avec un autre navigateur (Chrome ou Edge)
  • Redémarrez votre appareil

❌ L'appli ne fonctionne pas hors ligne

  • Ouvrez l'appli une fois en ligne pour que les fichiers soient mis en cache
  • Attendez 30 secondes
  • Fermez et rouvrez l'appli

❌ Les projets ne se lancent pas

  • Vérifiez que vous avez bien cliqué sur une carte de projet
  • Rechargez la page avec Ctrl + F5
  • Testez avec un autre navigateur
💡 Astuce : En cas de problème, désinstallez puis réinstallez l'application.
